MAFIA - Automated Test Runner

This page loads ../MAFIA.html in an iframe and runs integration tests by calling functions inside the game's window object. You must run this file from the repository root (so the iframe can load ../MAFIA.html). Serve via a local web server (e.g., `npx http-server .` or `python -m http.server`) and open this file from http://localhost:PORT/tests/MAFIA.test.html
